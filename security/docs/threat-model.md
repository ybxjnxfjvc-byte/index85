# Mini threat model — index85

## Scope

Публичный учебный кейс `Хекслет — система внутреннего обучения`, его статические файлы, браузерная сессия, локальное состояние и только те локальные лабораторные сервисы, которые лежат в этом репозитории.

## Assets

1. Целостность учебного контента и логики тренажёра.
2. Данные, вводимые посетителем в демонстрационные формы.
3. Состояние прохождения/результата, если оно сохраняется локально.
4. Конфигурация и секреты локальных лабораторных сервисов.
5. Целостность содержимого репозитория и публикации GitHub Pages.

## Trust boundaries

`visitor → browser DOM → local state → optional local lab`

`developer workstation → Git → repository → GitHub Pages`

## Risks and controls — Secure SDLC / quality gate / dependency inventory

| ID | Risk | Scenario | Control |
|---|---|---|---|
| T1 | Регрессия без проверки | Изменение ломает security-свойство | Automated quality gate |
| T2 | Секрет/бинарник в коммите | Репозиторий содержит лишнее | Repo gate по паттернам/размеру/типам |
| T3 | Непрозрачные зависимости | Нельзя быстро понять состав | Dependency inventory |
| T4 | Непроверенный release | Нет фиксированного prepublish шага | Release checklist + CI |
| T5 | Security-долг не зафиксирован | Ограничение забывается | Known limitations в SECURITY.md |

## Residual risk

Статический публичный кейс не превращается в промышленное приложение только из-за наличия security-документации. Там, где отсутствует сервер, серверные меры показаны только в локальных учебных лабораториях и не выдаются за часть реальной инфраструктуры компании.
